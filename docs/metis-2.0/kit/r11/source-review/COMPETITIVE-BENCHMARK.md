## Qualification protocol

Use an authorized comparative evaluation, not customer recordings or prohibited scraping. Before running, freeze tasks, reference answers, languages, device/network conditions, privacy mode, product versions and evaluation budget. Different capture/distribution entitlements must be disclosed rather than treated as identical. Start with a proposed 12-person mixed-role pilot and a task set large enough to expose repeated failures; report the actual sample and uncertainty. This is a study design, not a claim of statistical sufficiency.

Measure: verified supported-command completion; critical numbers/negations/owner errors; summary source coverage; unauthorized disclosure or action count; time to first genuinely useful outcome; user editing/rework minutes; share/CRM accuracy; installation/first-value/CPU/memory; operator reconciliation; and total speech/model/service cost with unknowns preserved. Reuse the main contract’s ASR and safety suites. Blinded reviewers must not see which product produced the anonymized artifact. Native/OS validation and consent requirements remain mandatory.

Publish a comparison only when actual terms, dates, methods and evidence support it. A product marketing sentence, this kit’s animation, or a signed EXE alone cannot establish “best in class.”
