A model is a provider route, not an authorization principal. A run is one bounded operation. A conversation may contain many runs. A service principal and an employee identity are never interchangeable.

Extend the existing Operator registry, mode/persona system and Dust agent discovery. First inventory existing IDs and pins. ### 32.4 Context lens: know exactly what was read

Build a bounded `ContextBroker` over existing capture, preprocessing, file import, brain retrieval and connectors. Resolve the user's explicit target first. Prefer structured source access when available and authorized; use scoped native accessibility semantics for the foreground window; use screenshot/OCR or visual inference only when it contributes evidence the structured source cannot supply. A screenshot is not permission to operate that application's UI or read all of its account.

A `ContextSnapshot` records source kind, stable target/record ID, exact principal and tenant, selected app/window/document, relevant display coordinate system, source revision/content hash, capture/read time, extraction method, selected range, coverage (`FULL`, `PARTIAL`, `VISIBLE_ONLY`, `UNAVAILABLE`), excluded material, sensitivity, allowed audiences and revocable lease. Derived content keeps source references and cannot broaden access. Content never goes into the operational ledger.

Read the current document beyond the visible page only through a verified file handle, selected attachment, supported application API or authorized connector. Resolve user-visible identity and revision before claiming the read is for the active file. Unsaved buffers differ from on-disk files: show which representation was obtained; prefer an approved active-buffer API or label disk-only coverage. Do not silently read a stale saved file and describe it as the current unsaved document. For paginated remote sources, exhaust the selected authorized scope or disclose the exact gap; list counts are not full-text proof.

The user sees compact source chips such as **Selected region**, **QBR brief · full text**, **Meeting summary · 09:00**, or **CRM · access needed**. A details drawer explains method, age, coverage and exclusions. The chip can remove or replace context. Removing it revokes use in uncommitted work and invalidates dependent approvals; completed external effects require reconciliation, not retroactive claims that data was never sent.

Use bounded extraction limits, streaming parsers and input sanitization. Macro execution, embedded scripts and remote image loads are disabled in document previews. Do not run code from a workbook or document to extract its text. Exact text, spreadsheet values, slide notes, page references and layout-sensitive fields remain linked to the original. When a query needs an unread section, either acquire it legitimately or explain the gap. “I see everything” is forbidden UI copy.

Capture user context before opening the overlay; exclude all Métis surfaces from screen capture. Pin the original app/window so the assistant does not describe itself. Do not append all previous screenshots to every turn. Context refresh is demand-driven, relevant to the task and bound to policy. A previous screen grant is not consent to continuous organizational activity logging. Never read password fields, protected browser sessions or private folders simply to personalize a greeting. Permission acquisition belongs to trusted Settings/native UI, not an agent manipulating its own permission controls.

### 32.5 Read, teach, draft and act are different modes

**Read** returns evidence from selected sources. **Teach** points to a supported target and explains the next step. **Draft** prepares content without changing the target. **Act** performs an exact authorized operation and verifies its effect. Show the selected mode in the expanded interface; the model cannot silently promote a Read request into Act.

For **screen guidance**, use native overlay annotations anchored to a recent app/window snapshot. An annotation carries target identity, display, normalized region, age, confidence and expected role. Prefer accessibility element bounds; coordinate-only hints are explicitly weaker. Scroll, resize, zoom, display move, window replacement or stale target invalidates the highlight. Reobserve before pointing again. A circle or arrow is not a permission prompt and cannot click through to activate its target. Clear annotations on Stop, app switch where relevant, lock, tour exit or permission revocation. On Windows use real work-area coordinates; never emulate a Mac notch.

For **dictation**, pin the deliberate destination field before capture, maintain the original spoken text and separate a verbatim result from an optional rewrite. Do not remove negation, accents, product IDs, amounts or punctuation under the label “cleanup.” Before insertion, revalidate the exact application, field, selection and focus generation. If the target changed, preserve the text and ask for the destination or offer an explicit copy action. Never paste into a password field, a newly focused chat, a search bar or a terminal merely because it now has focus. When using the clipboard as a fallback, respect explicit choice and prevent restoring or overwriting a clipboard value the user changed meanwhile.

For **actions**, preserve API/connector-first execution when it can solve the task cleanly. Visible browser control is a separate route and normally uses a task-owned window or an explicit user-selected current tab. Do not clone browser cookies, profiles or login state, disable security preferences, run hidden debugging servers or use undocumented OS input injection merely to appear instant. Verify native API/support and deployment eligibility before adopting any upstream computer-use helper. Where only foreground interaction is supported, explain the handoff and pause when the user takes over instead of pretending invisible background control works everywhere.

### 32.16 Concrete proof journeys and remaining reference gaps

**Agent/context golden path:** install the actual qualified lean core; identify the user; complete optional profile questions or skip them; confirm three definitions without starting work; select Research Scout; deliberately attach a source whose relevant fact is off-screen; prove full/partial coverage and the correct source revision; generate a scoped answer; hand an explicitly selected action to Follow-up Desk; approve its exact destination/content; verify one real external mutation and its readback; verify correct Mantu Intelligence/Dust scope and Operator attempt accounting. Run with the actual configured Jev and Laya variants, and record the exact native client/service/schema/policy identities.

**Collision path:** one agent holds the desktop input lease while a second has a private draft. A third arrives by voice with a similarly named alias. No draft or context leaks. Ambiguity is resolved without executing. The user changes the target, then says “do it”; stale approval is rejected. A remote callback arrives after Stop and cannot dispatch. A permitted already-started side effect is reconciled and its billing remains accurate.

**Onboarding failure path:** test muted output, denied mic, changed device, stale Entra session, missing driver, full disk, no network, partial source access, blocked connector, video failure, app update and replay. The user reaches the capabilities actually available without a hidden download or duplicate agent. Required policy checks cannot be skipped, but optional presentation never creates an inescapable screen.

**Reference gaps:** the DMG does not provide the complete original Swift source, server implementation, user data/export schema, entitlement state or evidence of native runtime success. The input was statically inspected only. A source string identifying a route is not authorization to call it. Dynamic black-box comparison requires an explicitly authorized disposable Mac test profile with real user-approved permissions and no personal credentials. There is no need to wait for that to implement independently specified Métis behavior; retain missing evidence rather than fabricate it.

**Release:** all 16 AGX gates and 32 AGUC cases retain explicit status. Required advertised agent features cannot vanish behind flags to claim full completion. Actual new capability approvals, paid infrastructure, DPO/privacy decisions, signing and public promotion follow existing owner controls. This plan creates no automations, agents, subscriptions, deployments or cloud accounts by itself.
