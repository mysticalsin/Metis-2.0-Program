Capability adoption map

r10 consolidation: onboarding follows MASTER §32.6/§34 and the retained Métis scene order. Any original eight-stage illustration below is historical reference, not an implementation instruction. Agent capabilities remain required. All 48 packaged Markdown resources receive a disposition. Fifteen are curated runtime SKILL.md files; the other guides are not separately established active capabilities. These are independent Métis implementation requirements, not redistributed HeyClicky instructions. Preserve the existing central registry. A capability can be implemented and still unavailable to a particular tenant or device; explain why and show its actual status.

The ordinary starter experience stays three agents, not 48 buttons or 48 running processes. Optional specialist/developer functions stay discoverable in the approved central catalog, with permissions and actual execution evidence. Location, personal messaging and wagering are not inferred enterprise defaults.
