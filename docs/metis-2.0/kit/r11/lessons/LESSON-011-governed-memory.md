# LESSON-011 · Memory is neither authority nor a retention exemption

1. A memory product introduces a deliberate persistent derived-content store. Disabling verbatim source copies does not mean nothing is retained.
2. A provider bank/key/tag does not establish the user’s source access. Bind real identity, output audience, revision and a fenced scope before inference; validate lineage again before returning content.
3. Upstream mental-model `is_stale` can miss deletion. Block reads immediately and reconcile source-dependent artifacts with application-owned tombstones and generations.
4. HTTP acceptance, searchable memory, current authorized evidence and a fully erased record are distinct states.
5. A synthetic UI check exposed a missing reset binding before release. Test every referenced control after assembling the HTML, not only the source modules.
6. A generated task-note insertion initially consumed a heading boundary. Validate exact task bodies and IDs after regeneration; document generation is part of the delivery pipeline.
7. Preserve the original Métis onboarding, animated orb-only ARMED and native Windows/Mac evidence gates. New memory infrastructure is not a license to redesign unrelated product surfaces.
