## 2. Source basis and important qualifications

The official HTTP reference displayed version **0.10.1**. The observed upstream main SHA was `b88458fd6b96e70069238f7df5a0e2f1c3c9240c`. Neither is a claim that an identified production image has been deployed or fully audited. Pin and qualify the actual service image/schema in the implementation environment.

The source review identified original-text storage, model tracing, durable operation payloads, unauthenticated defaults, permissive tag matching, global directives, derivative lineage and deletion limitations. The integration therefore starts with approved summaries/preferences/verified receipts; disables additional source-text and trace copies; separates service authentication from application authorization; and requires source-derived deletion/revocation fences. **Hindsight deliberately retains approved derived memory; it must not be advertised as zero-retention.** Cloudflare’s separate no-content-persistence requirements remain intact.

In particular, the documented mental-model stale flag does not observe source deletions. Métis must invalidate contaminated/obsolete derived results itself rather than trust that flag or remove only a citation after inference.

## 3. Actual components delivered

`memory/src/hindsight-client.mjs` implements bounded server-side HTTPS calls for version/readiness flags, retain, recall, reflect, document-source privacy inspection and exact-document deletion. It preserves Unicode, uses strict server-owned scope, constrains request/response size and time, withholds upstream error bodies, performs no implicit retry, and distinguishes unknown usage and unconfirmed outcomes.

`memory/src/memory-gateway.mjs` implements orchestration around required real Métis authority, canonical-store, fencing and ledger bindings. It rejects unavailable bindings, revalidates source permissions/revisions, withholds unauthorized synthesis, records uncertain mutations for reconciliation and tombstones before purge. **The actual database, distributed lease, Entra, API routing, production metering and application bindings are not provided by fixture tests.** Their implementation obligations are explicit in `memory/BINDINGS.md` and HMSTEP-01–16.

`memory/deploy/profile-check.mjs` implements 19 offline placement/privacy configuration checks. Its supplied profile deliberately fails until a reviewed image, region and stage approvals exist. It cannot create those approvals or establish actual infrastructure privacy.

`memory/live-smoke.mjs` can perform a real, cost-bearing synthetic retain → readback → recall → reflect → delete sequence in an authorized dedicated test bank. **It was not run against Hindsight here.** An invocation with no authorization flags exited 2 / NOT_RUN before network access, as intended. A successful future direct smoke is still not complete Métis or erasure qualification.
