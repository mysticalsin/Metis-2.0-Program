## 4. Two concrete defects reproduced without running the application

The original exported wake helper was TypeScript-transpiled and executed in isolation. Given `Hey Métis, crée une note intitulée “Québec / R&D”.`, it returned `hey cree une note intitulee quebec r d`. Accent/case/punctuation loss and leftover wake-prefix text are observable. The new contract requires normalized matching indices without replacing the user's original payload.

The original extracted D1 upsert builder was executed against synthetic SQLite data. A same-device late update with null usage replaced known 120 input / 30 output tokens with null. A different device could not overwrite the row, confirming a good control to preserve. These tests isolate source-expression semantics; they are not a deployed D1 or portal run.

The other two source probes anchor the existing 2,000-request dashboard list limit and native persistence error suppression. See source-results.json for exact boundaries. The source was not patched in this kit.

## 5. Defects found while producing this package

The new meeting test reused a document containing a deliberately immutable demo API; the second installation could not redefine it. The harness now uses a fresh page per case. Initial failure is retained; this was a test-harness defect, not a Métis production finding.

The new page layout exposed an existing synthetic hidden-view redraw: IntersectionObserver callbacks could request a paint despite the experience view being hidden. Drawing is now gated by actual visibility, intersection and dismissal, and the full broad and orb suites were rerun.

Initial ARMED inspector copy still named a solving/interpreting state. It now accurately labels the animated local-only visual. Stale static-r6 wording was removed from the active contract/native guidance; original history remains explicitly historical.

PDF checks caught narrow ID/risk columns fragmenting labels. Dedicated column widths now preserve all IDs visibly and in extracted text. A separate formatting pass repaired unbalanced priority emphasis. The final PDF was regenerated from the same master, not edited independently.

## 7. Reproduce and hand off

1. Extract to a new dedicated folder. Do not overwrite the application's AGENTS.md, worktree, hooks or release settings.
2. Open [OPEN-METIS-2.html](../OPEN-METIS-2.html), Play the simulated wake, inspect state controls and [the meeting workspace](../visual/meeting/index.html). Saying the name alone does not activate this HTML.
3. Review [the source-reconciled and target map](../architecture/index.html). Proposed services are not displayed as already deployed.
4. Run `python3 verification/verify_bundle.py` (Windows: `py verification/verify_bundle.py`). It checks the entire sealed file inventory and exits nonzero on failure.
5. In the real authorized repository, give Codex [CODEX-START.txt](../CODEX-START.txt). The complete contract is already in `spec/MASTER.md`; read relevant sections/task records, not the whole corpus every turn.
6. Keep new test results outside this immutable kit, or deliberately regenerate the inventory after an owner-reviewed modification. Read tests before executing in an approved existing Playwright/Chromium/TypeScript environment. No package installer runs automatically.
