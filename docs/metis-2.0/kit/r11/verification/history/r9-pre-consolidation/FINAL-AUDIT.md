## 4. Defects caught in this preparation

The first new browser run recorded **two failures**: IME composition handling and narrow-layout overflow. Both were fixed and the 28 checks rerun to completion. Later review corrected Read/Teach proposal semantics, suppressed source-stale in-flight responses, and removed stale cancellation copy on a new request. Final tests and captures use those corrected bytes. The initial failing report remains in `history/r9/agents-initial.json`.

The React/native integrations remain implementation tasks. The new pure reference is deliberately incomplete as an authentication service: it has no durable transaction store, cryptographic grants, OS input owner or actual policy engine. The HTML’s fake timers, readiness labels, source records and result receipts may not ship as production behavior.
