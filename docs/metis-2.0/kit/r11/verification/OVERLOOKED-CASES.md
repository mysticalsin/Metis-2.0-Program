# Overlooked cases now included

The canonical requirements are in MASTER §28–30 and each task's source/experience closure references. This index is a navigation aid, not another competing specification.

| Case | Required treatment | Primary record |
|---|---|---|
| Animated idle orb versus accessibility and power | Solving geometry by default; pause for reduced motion, hidden/offscreen/locked/energy states; no false audio or cloud use. | SRC-14, EXP-10 |
| A regex wake matcher versus an acoustic wake detector | Trusted local audio activation before cloud upload; normalization only for matching, preserve original arguments. | SRC-06 |
| Jev response exists but never affects the plan | Apply a validated candidate decision with version/generation binding and independent authority. | SRC-03 |
| Adapter promise resolves with failed/unknown outcome | Inspect actual result, verify postcondition, bound retries and reconcile uncertain writes. | SRC-04, SRC-05 |
| Native save reports an object even after failure | Explicit persistence result and readback; no swallowed errors or hidden full-transcript archive. | SRC-11, SRC-12 |
| Cloudflare speech key remains on the desktop | Authorized session broker and server-held organization credentials; no convenience embed in enterprise profiles. | SRC-07–09 |
| Missing gateway and a failed configuration read | No auto-created logging defaults; actual response/config readback; fail unavailable secret inventory safely. | SRC-08, SRC-20 |
| A late telemetry event removes actual token values | Authoritative field merge, attempt identity and complete-window aggregates independent of UI pagination. | SRC-10 |
| Voice identity persists beyond the session | Ephemeral diarization and explicit verified roster mapping; no automatic named voiceprint enrollment by default. | SRC-13 |
| Public GitHub release tag disappears later | Reverify actual mirror/ref ownership and both source/release destinations before promotion; preserve protections. | SRC-18 |
| Test/doc paths excluded from secrets scanning | Narrow reviewed synthetic exceptions, scan all other content and actual artifacts. | SRC-19 |
| Operator store box hides real persistence | Store interface, D1 implementation, database identity and independent legacy license durability are explicit. | SRC-02, SRC-17 |
| Human notes overwritten by better-sounding text | Preserve verbatim original and reviewed enhancements separately; citations name actual available evidence. | EXP-02, SRC-22 |
| A completed task is only a pretty CRM card | Exact target/field preview, trusted approval and committed readback; drafts are not external sends. | EXP-04, EXP-09 |
| Botless desktop capture confused with automatic joining | Qualify each source mode, permission/notice path, lifecycle and single-source handover independently. | EXP-07 |
| A checklist, directory or mock reports success | Distinguish source evidence, test run, deployment and native artifact qualification. | SRC-01, SRC-23, SRC-24 |

The remaining deeper contract includes transcript fidelity, long-meeting bounded memory, policy drift, reconciliation after crashes, audience-safe Dust writes, revoked skills, device changes, stable upgrades, source exports, and privacy rights. Do not drop the earlier 112 cases just because these refinements have new labels.
