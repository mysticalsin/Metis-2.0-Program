## 2. Actual collaboration tooling

`tools/dual_agent.py` is an implemented Python utility, not a planned stub. It creates private packets bound to real clean Git commits, the actual changed-file inventory, source hashes, task requirements and the master contract. It checks reviewed source against that snapshot, rejects stale/dirty/mismatched inputs and false test/release claims, and never resets user work.

Its optional `review` operation invokes an already installed actual Claude CLI only after explicit source-egress and reviewed-configuration approval, with an explicit permitted model and spending/turn/time limits. It uses stdin for the prompt, captures real exits and response metadata, preserves failed attempts, and never claims that a response equals a passing review or product test. Local CLI configuration/hooks remain a separate trusted-environment prerequisite; a tool list is not an OS sandbox. The kit includes no model account, token or hidden remote service. **No actual Fable/Claude session was called during preparation.**

Codex leads integration. Fable independently reviews or implements bounded disjoint slices. Exact source ownership, reviewer identity, native proof and release authority remain separate. The source-review JSON checker validates consistency, not actor authenticity or semantic correctness.

## 6. Use and reproduce

1. Extract the ZIP into a new dedicated handoff directory beside the actual repository. Keep private source and review outputs within approved environments.
2. Give Codex `CODEX-START.txt` and the paths to this kit and the actual checkout. Give the real Fable/Claude session `FABLE-START.txt` when available.
3. Inspect `OPEN-METIS-2.html`, `onboarding/preview/index.html`, the agents and meeting workspaces, and architecture map.
4. Run `python3 verification/verify_bundle.py` or `py verification/verify_bundle.py` on Windows. This checks the delivery kit only.
5. Work through the existing task dependencies and `delivery/RUN-ORDER.md`. Read relevant master sections with `tools/read_task.py`, not the whole archive per task.
6. Store new execution/review/product receipts outside the sealed kit. A changed candidate, source, policy or service invalidates affected old acceptance evidence.
