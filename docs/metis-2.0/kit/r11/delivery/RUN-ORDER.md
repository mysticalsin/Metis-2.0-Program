# Numbered execution order

Use existing TASK and AGSTEP dependencies. Phase numbers are checkpoints, not a license
to skip acceptance or make every task wait for the slowest independent platform.

1. **TASK-001–005:** actual source/deployed baseline, full input reconciliation,
   bounded plan, interfaces, graph freshness, real tool/signing/service discovery.
   Qualify Codex/Fable access and run a small real review before scaling it.
2. **Early TASK-027.A/028.A:** fix the two P1 blockers and right-edge input in a
   minimal reviewable release-branch patch set after their shared prerequisites.
3. **TASK-006–010:** cross-surface identity, canonical knowledge authority, retained
   onboarding/simple Settings, central skills and meeting eligibility contracts.
4. **TASK-011–020:** real private Cloudflare route, server secrets/session grants,
   audio ownership, faithful partial/final transcript, trusted wake and cancellation.
5. **TASK-021–030:** explicit optional packs, small verified installers, retained
   Métis onboarding + OBU-01–05, native Mac architecture and real orb/bar wiring.
6. **TASK-031–034:** actual Jev and Laya adapters, authorization/verification for
   native actions and authoritative shared consumption ledger. Qualify each route.
7. **TASK-035–045:** canonical Intelligence, projections, scoped Dust reads/writes,
   central skills, simplified settings and the actual deployed Operator portal.
8. **AGSTEP-01–18 within their parent TASK lanes:** retain all named-agent/context/
   capability study work; do not create a parallel product, runtime or wizard.
   Agent creation never auto-runs work. One trusted native input owner.
9. **TASK-046–052:** authenticated Teams surfaces, eligible actual-start events,
   admission/qualified media, source ownership and audience-safe output.
10. **TASK-053–060:** evaluate actual transcript/knowledge quality and run full
    native/service/rights/failure journeys; preserve denominators and real metrics.
11. **TASK-061–062:** characterization-backed refactoring, source-map efficiency,
    deployed operations, backup/restore, rollout/rollback and incident drills.
12. **TASK-063–066:** freeze real signed Windows candidates, independent final
    review, native/service qualification, approved unchanged publication and
    download verification. Separate native Mac public-signing hold; full residual
    scope/evidence and continuation report.

Every slice uses inspect → plan → implement → test → independent review → fix
→ real integration → checkpoint. Review and privacy tests happen throughout,
not only at the end. Ready-to-type, provider-ready, action-attempted and
verified-result are distinct. No skeleton or simulated result closes a product gate.

## Memory implementation order

Establish source/retention/identity before retain; canonical projection before recall; revocation/purge fences before richer models; then UI, Dust/skills, full accounting, quality, security, migration, real cross-platform proof and release.
