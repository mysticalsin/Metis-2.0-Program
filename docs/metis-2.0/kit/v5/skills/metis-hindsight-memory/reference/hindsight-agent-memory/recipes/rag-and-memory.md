# Recipe · RAG plus experience memory


Keep policies, manuals, current contracts and code in canonical retrieval systems.
Use Hindsight for durable preferences, prior decisions and useful experience. Route a
current policy or exact quotation request to the original approved source, not a stale
reflection. Memory can identify which source is likely relevant without becoming its
replacement.

Merge results only after current access and revision checks. Distinguish canonical
statements, extracted assertions and derived conclusions in the evidence envelope.
Resolve contradictions in favor of authoritative current source for current-state
questions; preserve historical facts with clear timestamps when the task asks history.

Apply one combined context budget after deduplication. Do not include full RAG chunks,
full memory chunks and full reflect output for every request. Recall first; synthesize
once. Use mental models only for repeated questions over a stable allowed cohort.

Acceptance: a changed policy supersedes an older lesson, an exact quote comes from the
actual source, access revoked in the document system also excludes memory derivatives,
and memory-off still answers appropriately from canonical knowledge.
