55 files of the uploaded generic v1.0.0 skill unchanged, including its checksum list,

Read `METIS-PROFILE.md` first. The nested generic skill is reference content; do not
register it as an independent auto-capture skill. The profile specializes the uploaded
skill for Métis's existing r11 memory gateway, Entra/Operator, source authorization,
JEV, note-taking and keyboard behavior. It creates no installed runtime or credentials.

In the full upgrade package, the developer follows `memory/INTEGRATION.md` and the
updated `delivery/IMPLEMENTATION-PROMPT.md`. Hindsight is a required upgrade capability,
not a hidden substitute for notes or an automatic archive of recordings.

The original clients and tests can be used without package downloads. Their tests use
synthetic data and local/fake transports; see the upstream VERIFICATION.md. Native/live
qualification is separate. Live smoke and local Compose are opt-in references only.
