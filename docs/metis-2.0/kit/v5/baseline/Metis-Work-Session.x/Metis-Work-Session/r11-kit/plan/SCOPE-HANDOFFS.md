### 21.1.2 Explicit slice handoffs: what may start and what may close

These handoffs are the required decomposition where a root task spans independent platforms or a later integrated result. Other tasks may keep one slice. Create these names in the execution registry before running its scoped-DAG validator. Referencing `.ADAPTER` requires that adapter's actual contract/service proof, not its parent task's later UI or business demonstration.
