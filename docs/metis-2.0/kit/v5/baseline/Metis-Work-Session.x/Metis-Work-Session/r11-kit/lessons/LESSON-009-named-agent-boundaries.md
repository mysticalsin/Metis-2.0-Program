# LESSON-009 — names, source scope and completion need different contracts

Source: r9 handoff preparation, not a production incident.
1. A named agent is a versioned definition, not a new privilege or a running model process.
2. Full/partial/visible-only context cannot be implied by a screenshot or file title.
3. The initial HTML used property-based composition handlers that did not fire in the exercised Chromium path. Registered composition event listeners now prevent early submission.
4. A narrow grid inherited the agent rail’s min-content width. A bounded minmax(0,1fr) column and scrolling rail removed the overflow.
5. Read/Teach modes must not produce an actuation proposal. Source change during an in-flight response suppresses stale completion, not only the later approval.
6. A stale cancellation toast must be cleared when new work starts; pending approval has its own truthful status.
7. Static/compiled strings prove intent, not dynamic behavior. Native and service demonstrations remain required.
