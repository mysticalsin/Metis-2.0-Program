## Recording setup

Use a landscape frame, a stable eye-level camera, a quiet room, a simple background and clear speech. 1080p at a normal frame rate is sufficient for the intended welcome; keep an original-quality master and a compact deployment encode. Allow extra framing room so the product can contain the video without cropping your face, name or captions. Do not stretch it or use the old decorative full-bleed crop behavior for spoken video.

Leave a brief clean pause at the start and end. Record one natural version and one slightly slower version. Avoid background music in the spoken master; the application already owns any permitted ambient audio, which must not overlap the narration.

For screen capture, use synthetic content. Close notifications and other applications. Remove other people's names from tabs, accounts, calendars, file paths, sample meetings, lower-thirds and visible browser history. Do not expose email addresses, customer information, secrets or access codes. A personal welcome needs only Tony Walteur's name.
