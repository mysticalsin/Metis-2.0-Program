6. Other current controls, right-edge modes, reduced motion, light/forced-color, interrupted scripts and graphics fallback remain acceptance cases. Verify real Windows/native Mac window geometry, not CSS only.
7. The meeting workspace is a separate synthetic reference for EXP-01–07/11. Human notes and proposed enhancements remain distinct; approved changes have exact revision/destination; no raw audio or real service calls.
8. Verify actual motion over time, not a still screenshot. The kit tests frame variation, deterministic source math, pause/resume and interaction; true frame pacing/battery/native capture require product qualification.
