## r6 mandatory orb-only host behavior

ARMED is one transparent, fully visible 64-point mesh in an approximately 72-point hit target. No notch background, bar, caption, border beam, status label or aura is present. Only keyboard focus may show an outline. OFF/locked/signed-out must not masquerade as ARMED; tray/menu and keyboard recovery remain available. Fresh installs still require explicit wake opt-in.

Use a real native accessible button (Enter/Space and VoiceOver), separate from the active composer. An intentional click opens typed mode, not microphone capture. A trusted detected wake requests the active bar; it must not steal another app's text focus. Passive hover never expands the ARMED orb, records or calls an API. Preserve permitted hover behavior only for a separately selected legacy non-armed handle; the latest ARMED requirement wins.

The main/native window owner must shrink both visible AND interactive bounds to the orb, and restore the correct active panel bounds inward from the chosen display. CSS transparency does not make a whole Electron/NSPanel window click-through. Test the real host window with an app underneath: clicks outside the orb and caption/card areas must reach the correct app. Do not make the orb itself click-through. Account for focus outline/safe insets and right-side OS controls without negative-margin clipping. Reparenting a Canvas in the browser demo does not implement AppKit/Win32 window geometry.

Keep open while typing/composing, in approval, or unresolved error. Escape first belongs to an active IME; otherwise route active Stop or typed dismissal through the controller. A keyboard-opened composer returns to the orb on dismissal without discarding a permitted draft. Do not restore focus to an old app after a user-directed focus/open action deliberately changed the target.

Treat every wake callback as untrusted until its source, active local owner, permissions, session generation and lifecycle are validated. Coalesce duplicate callbacks; a wake during typing, approval or running work must not replace the draft, target or approval. Lock/logout/permission loss revokes the relevant local authority; reactivation is explicit. A separately authorized meeting service has distinct capture and remote-stop controls. Never hide OS capture indicators to make the orb clean.

Pause the actual library clock, not just CSS opacity. ARMED uses the animated Libraries.dev solving motion by default, not the superseded static r6 pose. Hidden/minimized/reduced-motion/energy-paused states do no unnecessary drawing. Preserve the visual pose rather than resetting the mesh on every repaint. Qualify a static mesh fallback if the effect fails. This reference does not claim measured native idle CPU or GPU savings.

A dormant preserved draft does not disable valid wake while ARMED. The controller parks it in its permitted local volatile draft store, keeps it out of voice/provider context, and restores it on typed entry/dismissal. Active composition is not interrupted. A wake must not call focus even if the launcher previously had keyboard focus.
