## 0. Executive summary

Sections §15–§20 describe a large expansion of what Métis 2.0 must become — a governed enterprise meeting/knowledge platform (Teams bot, Entra-wide identity, "Mantu Intelligence" governed knowledge service with a Dust MCP read/write surface, formal no-content-retention controls, a stable M2-* requirement register, and Windows/Mac release gates) — layered on top of what today's `v1.9.6` repo actually is: a mature, heavily self-audited **single-user desktop app** (Electron + local/cloud LLM, local ASR, an Operator Cloudflare Worker backend, and a nascent Intelligence sub-app) with **no Teams integration of any kind**, **no MCP surface exposing Métis's own knowledge to Dust**, and a "Mantu Intelligence" feature that today means something much narrower ("connect an existing OneDrive brain, show cross-meeting links") than what §17 specifies (canonical record model, provenance states, audience-scoped MCP tool contract, Graphify projection adapter, Dust read **and write**).

Concretely, of the ~20 M2-* stable requirement IDs whose substantive definition sits inside my assigned §15–§20 prose range:
