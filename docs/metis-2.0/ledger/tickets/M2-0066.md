## Summary

The live transcript lives only in renderer React state with a 60 s autosave into the OneDrive folder, which is why automatic renderer recovery was forbidden. An append-only, envelope-encrypted journal in userData with renderer acknowledgements guarantees zero loss of acknowledged revisions across SIGKILL and unblocks journal-gated recovery in m6. It obeys the active retention profile.
