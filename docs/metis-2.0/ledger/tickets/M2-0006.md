## Summary

Today the audit log cannot tell a force-quit from a clean quit, a brief stall from a wedge, or a real crash from a handled rejection, so every freeze hypothesis rested on inference. Add the content-free events designed in docs/metis-2.0/ARCHITECTURE.md C9 so the packaged build discriminates the hypotheses. These events are additive and ship in 1.9.7.
