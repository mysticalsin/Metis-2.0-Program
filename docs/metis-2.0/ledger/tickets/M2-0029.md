## Summary

On Windows, libuv places non-detached children in a kill-on-close job but allows silent breakaway for grandchildren; this is ASSUMED from libuv source and unverified against Electron 43. HK-W measures it on the windows-latest lane. A supervise.exe with a private job is built only if descendants survive; that binary would itself need signing, which is blocked until the signing route exists.
