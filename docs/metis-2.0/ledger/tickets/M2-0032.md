## Summary

With the gateway, History receives per-row availability instead of waiting on the slowest download. Design how unavailable rows look and how a user opens one on purpose, so an offline OneDrive shows a usable list within 2 s. Add the renderer marker that tells the toggle-race no-op apart from a real freeze.
