## Summary

The kit's section 27 linter cannot pass without a per-ID matrix: 937 inventory rows (921 unique IDs) across 37 families, most cited only as ranges. Build the matrix from ledger/tickets.json and the inventory, give each ID a repo status derived from ticket status and evidence, and fail CI on an unmapped ID or a dangling ticket reference. This also serves as TASK-003's bounded source map and numbered handoff.
