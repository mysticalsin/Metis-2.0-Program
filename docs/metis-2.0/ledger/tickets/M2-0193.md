## Summary

History list and search fan out uncapped async reads that can pin every libuv thread on undownloaded files, so the History spinner never ends even when the main thread is free. With dataless detection (M2-0191) and the gateway core (M2-0030), list and search stop reading cloud-only files at all.

## Acceptance

- [ ] recall.ts has no node:fs import (FF-05b hard rule for this file)
- [ ] List and search skip files classified dataless or unknown and return them as 'not downloaded' rows; an explicit open hydrates one file with progress under a content permit
- [ ] READ_CACHE_MAX clear-all replaced by an LRU; failed reads cached so a keystroke does not retry every file
- [ ] Superseded searches cancelled through AbortSignal at the queue level
- [ ] Packaged ST-1 on the lane candidate: History open and search with the FIFO and real dataless fixtures give main p99 < 50 ms and a usable degraded list within 2 s; ST-1-W result recorded
