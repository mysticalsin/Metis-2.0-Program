## Summary

A SIGKILLed main (force quit after a stall) leaves each llama-server reparented to launchd at about 3.1 GB, and nothing reaps it. The B2 proposal ('the single-instance lock guarantees a live registry PID is ours') is unsafe because PIDs are reused across reboots. Each session writes its own append-only registry with OS start time and executable realpath, and the boot reaper kills only entries whose identity matches exactly; a narrow legacy rule cleans pre-1.9.7 llama-server orphans that have no registry.
