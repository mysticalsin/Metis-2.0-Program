## Summary

A reaper only cleans on the next launch; the machine stays heavy until then. The existing Swift mac-helper gains a supervise mode that puts the sidecar in its own process group, watches the parent with kqueue NOTE_EXIT (with a getppid race check) and kills the group when main dies, so orphaning ends at the source. Default-on only if HK-M passes 20 of 20 on the packaged build; otherwise the flag stays off and the registry/reaper remains the net.
