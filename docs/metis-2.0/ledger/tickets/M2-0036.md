## Summary

In the owner's Hide layout the overlay rests as a visible, opacity-0, click-through 8x2 hairline, so macOS reopen (activate, not second-instance) calls showInactive() on an already-visible window: a deterministic no-op even when the app is healthy. Five divergent reveal snippets exist. One controller now serves activate, second-instance, tray, hotkey and notification click; an explicit reopen restores the interactive layout. No automatic renderer reload ships in 1.9.7.
