## Summary

runSelfTest overwrites and deletes the live settings.json and managed-config.json and temporarily redirects the real meetingsFolder setting, guarded only by a persistable ASKTOTO_SELFTEST env var on unpackaged launches. An interrupted run can leave the real profile pointed at a deleted directory. Give self-test its own userData via app.setPath before any settings access.
