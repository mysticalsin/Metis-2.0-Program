## Summary

EXP-12 asks for an evidence-based comparison, not a feature count: the same consented tasks, languages, hardware, network and privacy scope, run against competitor products that the program can legitimately use. The resource census (M2-0009) covers only the footprint half, and no other ticket runs the comparison. Pre-register the slices and the rubric, run them on the frozen candidate with synthetic meetings only, and report failures, abstentions and uncertainty. Competitor references R81..R85 come from the kit; which products are compared is the owner's call.
