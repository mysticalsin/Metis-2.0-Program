## Summary

People, devices, sessions, operations and attempts are conflated; late client events overwrite server usage; rate limits use non-atomic read-then-write. Separate the identities, bind identity at event time, keep server usage authoritative, price speech by duration/transport/channel/reconnect, and make settlement concurrency-safe.
