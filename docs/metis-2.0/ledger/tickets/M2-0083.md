## Summary

Every layer of the command-mic feature exists and is tested, but nothing joins them: no recognizer calls ingestTranscript, no producer fills the proposal preview, the card is never mounted and no adapter ever returns 'verified'. Join the hops so a spoken or typed command produces a visible, confirmable, verified result.

## Acceptance

- [ ] A recognized command reaches MetisCommandRuntime.ingestTranscript; the typed-input path is equivalent and runs the same policy and verification path with no microphone access (UC-003)
- [ ] Main generates an allowlisted preview string; CommandProposalCard is mounted with Confirm and Cancel; Escape cancels
- [ ] Confirm consumes the single-use proposal; the adapter returns 'verified' only after readback; 'unknown' is shown as unverified
- [ ] Packaged test: 'Métis, open Notes' produces a verified result
