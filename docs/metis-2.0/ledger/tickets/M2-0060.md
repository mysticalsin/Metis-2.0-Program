## Summary

The IPC guards (assertMainWindow, denyIfLimited, assertBrainReader) are free functions inside a 9,519-line file and 164 handlers sit in one 4,147-line registerIpc(). Create the composition seams every later extraction needs: a plain AppContext object passed explicitly (not a DI container or event bus), the guards moved verbatim, and a registerHandler that does not compile without a schema and a guard.
