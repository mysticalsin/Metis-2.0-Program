## Summary

The meeting experience contracts require preparation before meetings, useful and quiet live assistance, and capture choices with truthful recovery. Private assistant output never enters the transcript, replies default to text during calls, and a long meeting keeps bounded private working memory. Competitor references (R81..R85) inform qualification, not scope.
