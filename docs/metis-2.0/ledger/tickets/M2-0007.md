## Summary

Every packaged suite (hard-kill, stall, reveal, recovery, budgets) needs a machine with no Métis install and no owner data. The fallback is not the owner's primary account (it shares the Keychain safeStorage item, TCC grants and sidecar reaper scope with the live install) but a separate macOS user on the owner's Mac, which takes about five minutes. A dedicated test cloud account gives real dataless files. The GitHub windows-latest runner covers what it can; a managed Windows 11 laptop covers ST-1-W, HK-W, the census, GPU, DPI and battery.
